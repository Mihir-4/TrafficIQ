# 1. Introduction

Object detection alone is insufficient for intelligent traffic analysis.

YOLO detects objects independently in every frame, meaning the same vehicle receives a new detection each frame without maintaining its identity.

Example

Frame 1

```
Car detected
```

Frame 2

```
Car detected
```

Frame 3

```
Car detected
```

YOLO has no knowledge that all three detections belong to the same vehicle.

For TrafficIQ, we require persistent identities so that vehicles can be tracked across multiple frames.

This is the responsibility of the tracking system.

---

# 2. Why Vehicle Tracking?

Without tracking, the following tasks become impossible.

- Counting unique vehicles

- Measuring traffic flow

- Estimating congestion

- Preventing duplicate counting

- Calculating vehicle trajectories

- Estimating waiting times

- Future speed estimation

Tracking transforms independent detections into continuous object trajectories.

---

# 3. Why ByteTrack?

Several tracking algorithms were evaluated.

| Tracker | Selected |
|----------|----------|
| SORT | ❌ |
| DeepSORT | ❌ |
| StrongSORT | ❌ |
| OC-SORT | ❌ |
| ByteTrack | ✅ |

---

## Reasons for Selecting ByteTrack

### High Accuracy

ByteTrack maintains stable object identities even in crowded traffic scenes.

---

### Lightweight

Runs efficiently on consumer GPUs.

Suitable for real-time inference.

---

### Ultralytics Support

ByteTrack integrates directly with YOLO11.

Minimal implementation effort.

---

### Excellent Traffic Performance

Designed for crowded multi-object tracking.

Traffic scenes contain:

- Cars

- Bikes

- Trucks

- Pedestrians

- Buses

ByteTrack performs well under these conditions.

# 11. Vehicle Counting Strategy

One of the biggest mistakes in beginner traffic projects is counting detections.

Incorrect

Frame 1

```
Car detected
```

Count = 1

Frame 2

```
Car detected
```

Count = 2

Frame 3

```
Car detected
```

Count = 3

One car becomes three vehicles.

Wrong.

---

Correct Method

Each Track ID should only be counted once.

Example

```
Track ID

15

↓

Already Counted?

↓

No

↓

Count++
```

Later

```
Track ID

15

↓

Already Counted?

↓

Yes

↓

Ignore
```

Maintain

```
counted_ids = set()
```

Never count the same ID twice.

# 12. Line Crossing System

↓

Only when the center of the bounding box crosses the line should the vehicle be counted.

This prevents premature counting.

# 5. Vehicle Counter Module

Vehicle counting should be completely independent from tracking.

Tracking only assigns IDs.

Counting decides whether a vehicle should increase the count.

---

## Counting Logic

Vehicle enters frame.

↓

Tracker assigns ID.

↓

Has this ID been counted?

↓

NO

↓

Wait until vehicle crosses counting line.

↓

Count++

↓

Store ID.

---

Later

Vehicle still visible.

↓

Same Track ID.

↓

Already Counted?

↓

YES

↓

Ignore.

---

# Internal Data Structure

The vehicle counter should maintain a persistent set.

Example

```python
counted_ids = {

    7,
    11,
    18

```

```
↓

YES

↓

↓

NO

↓

Count Vehicle
```

This guarantees every vehicle is counted exactly once.

# 1. Introduction

Traffic analytics is not simply counting vehicles.

A road containing 20 moving cars may actually be less congested than a road containing 8 stationary trucks.

Therefore, TrafficIQ separates **traffic density** from **traffic congestion**.

These are two different concepts that together provide a realistic understanding of road conditions.

---

# 2. Traffic Density

Traffic Density measures **how many road users occupy the camera view at a given moment.**

It does not consider whether they are moving.

Example

| Vehicles Visible | Density |
|-----------------|----------|
| 3 | Very Low |
| 9 | Low |
| 18 | Medium |
| 32 | High |
| 50+ | Very High |

Density is calculated for every processed frame.

---

# 3. Traffic Congestion

Congestion represents **how difficult it is for vehicles to move.**

Congestion depends on more than vehicle count.

Factors include:

- Number of vehicles
- Vehicle types
- Occupancy
- Frame-to-frame consistency
- Queue formation
- Future: vehicle speed

Congestion is therefore a higher-level metric than density.
